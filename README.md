# Yona for VS Code

[Yona](https://github.com/yona-projects/yona) 이슈트래커/코드리뷰 서버를 VS Code 안에서 바로 쓸 수 있게 해주는 확장입니다.

## 현재 지원하는 기능

- **서버 관리**: 여러 Yona 서버를 등록하고 상태바에서 전환
- **인증**: Yona 개인 액세스 토큰으로 로그인, 연결 테스트
- **이슈 트래커**:
  - 사이드바에서 등록된 프로젝트별 이슈 목록 확인
  - 이슈 상세(담당자, 마일스톤, 기한, 라벨, 코멘트 이력 포함) 보기, 코멘트 작성
  - 이슈 닫기/재열기
  - **새 이슈 폼**: 프로젝트, 제목, 본문, 담당자, 마일스톤, 기한, 라벨을 한 화면에서 입력해 만들기. 프로젝트가 여러 개 등록되어 있으면 폼에서 고르고, 트리의 프로젝트 행에서 `+`로 열면 그 프로젝트가 미리 선택됩니다.
  - 현재 파일의 특정 라인을 기준으로 새 이슈 생성(같은 폼이 열리고 본문에 `파일경로:줄번호`가 채워집니다)
  - 프로젝트 등록: 내가 속한 프로젝트 목록에서 여러 개를 한 번에 고르기(직접 입력도 가능)
- **커밋 메시지 연동**: SCM 입력창에서 `#12` 같은 이슈 번호 자동완성, 클릭 시 이슈 상세로 이동

## 시작하기

1. 왼쪽 활동 표시줄의 Yona 아이콘을 열고 사이드바의 **서버 등록** 버튼을 누릅니다(명령 팔레트의 **Yona: 서버 등록**도 같습니다). 서버는 더 필요하면 사이드바 제목줄의 서버 아이콘이나 하단 상태바의 서버 이름을 눌러 목록 끝의 **서버 추가...**로 등록하고 전환합니다. 설정 파일(`settings.json`)을 직접 고칠 필요는 없습니다.
2. **Yona: 로그인 (토큰)**으로 개인 액세스 토큰을 등록합니다. 이슈를 만들고 고치려면 `repo` 범위가 필요하고, 공개 프로젝트의 이슈만 다루면 `public_repo` 범위로 충분합니다.
3. **Yona: 연결 테스트**로 정상 연결을 확인합니다.
4. **Yona: 프로젝트 등록**으로 사이드바에 표시할 프로젝트(`owner/name`)를 추가합니다.

## 설정

| 설정 | 설명 |
|---|---|
| `yona.servers` | 등록된 Yona 서버 URL 목록 |
| `yona.currentServer` | 현재 선택된 Yona 서버 URL |
| `yona.projects` | 사이드바에 표시할 프로젝트 목록(`"owner/name"` 형식) |

## 요구 사항

- Yona v2 서버(자체 호스팅) 접근 권한과 개인 액세스 토큰

## 서버 API

확장은 Yona v2 서버의 외부 API(`/-_-api/v1`)만 사용하며, 인증은 모든 요청에 `Authorization: token <값>` 헤더로 보냅니다.

| 기능 | 호출 |
|---|---|
| 연결 테스트 | `GET /-_-api/v1/user` |
| 이슈 목록(열린 것) | `GET /-_-api/v1/owners/{owner}/projects/{project}/issues?state=open` |
| 이슈 상세 | `GET .../issues/{number}` |
| 이슈 생성 | `POST .../issues` (본문 `{"issues":[{"title","body"}]}`, 응답의 `location`으로 이슈를 다시 조회) |
| 이슈 닫기, 다시 열기 | `PATCH .../issues/{number}` (본문 `{"state":"closed"}` 또는 `{"state":"open"}`) |
| 댓글 목록 | `GET .../issues/{number}/comments` |
| 댓글 작성 | `POST .../issues/{number}/comments` (본문 `{"comment":"..."}`) |
| 내게 배정된 이슈 | `GET /-_-api/v1/user/status` |

예전 서버(Yona 1.x 계열)의 `/api/v1/...` 경로와 "레거시 전권 토큰"은 더 이상 쓰지 않습니다.
