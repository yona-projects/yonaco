# Yona for VS Code

[Yona](https://github.com/yona-projects/yona) 이슈트래커/코드리뷰 서버를 VS Code 안에서 바로 쓸 수 있게 해주는 확장입니다.

## 현재 지원하는 기능

- **서버 관리**: 여러 Yona 서버를 등록하고 상태바에서 전환
- **인증**: 스코프(fine-grained) 토큰 또는 레거시 전권 토큰으로 로그인, 연결 테스트
- **이슈 트래커**:
  - 사이드바에서 등록된 프로젝트별 이슈 목록 확인
  - 이슈 상세(코멘트 이력 포함) 보기, 코멘트 작성
  - 이슈 닫기/재열기
  - 현재 파일의 특정 라인을 기준으로 새 이슈 생성
- **커밋 메시지 연동**: SCM 입력창에서 `#12` 같은 이슈 번호 자동완성, 클릭 시 이슈 상세로 이동

## 시작하기

1. 명령 팔레트(`Cmd+Shift+P` / `Ctrl+Shift+P`)에서 **Yona: 서버 등록**을 실행해 Yona 서버 URL을 등록합니다.
2. **Yona: 로그인 (토큰)**으로 발급받은 스코프 토큰을 등록합니다(라인 리뷰 코멘트·온라인 커밋 같은 레거시 전용 기능이 필요하면 **Yona: 레거시 전권 토큰 등록**도 함께).
3. **Yona: 연결 테스트**로 정상 연결을 확인합니다.
4. **Yona: 프로젝트 등록**으로 사이드바에 표시할 프로젝트(`owner/name`)를 추가합니다.

## 설정

| 설정 | 설명 |
|---|---|
| `yona.servers` | 등록된 Yona 서버 URL 목록 |
| `yona.currentServer` | 현재 선택된 Yona 서버 URL |
| `yona.projects` | 사이드바에 표시할 프로젝트 목록(`"owner/name"` 형식) |

## 요구 사항

- Yona 서버(자체 호스팅) 접근 권한과 API 토큰
